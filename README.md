# Marathi Alphabet Tracing Fun

A kid-friendly, interactive web application to help children learn and trace the Marathi alphabet (Devanagari script).

## Features

- **Interactive Tracing**: Kids can trace the letters using a mouse or touch screen (perfect for iPads/tablets). The drawing is beautifully restricted within the lines using an HTML5 Canvas clipping mask.
- **Natural Voice Audio**: High-quality, natural human voice pronunciations for all Marathi vowels and consonants.
- **Picture Matching Game**: A fun, interactive mini-game where kids must choose the correct picture (Emoji) that corresponds to the starting letter of the current alphabet.
- **Visual Feedback**: Colorful animations and visual cues for correct and incorrect answers.
- **Offline Audio Support**: Audio files are downloaded locally for fast, reliable playback.

## Technologies Used

- **HTML5 & CSS3**: Vibrant, rounded, kid-friendly design system using CSS variables.
- **Vanilla JavaScript**: Lightweight state management, Canvas API manipulation, and pointer event handling.
- **HTML5 Canvas**: Powers the drawing and hit-testing mechanics.
- **Web Audio API**: Plays high-quality `.mp3` files locally.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ajitkatharcodehub/kid-marathi-learn.git
   ```
2. Navigate into the directory:
   ```bash
   cd kid-marathi-learn
   ```
3. Start a local server (e.g., using Python):
   ```bash
   python3 -m http.server 8000
   ```
4. Open your browser and navigate to `http://localhost:8000`.
